Como funciona o módulo Notificações
Este módulo permite gerar e enviar comunicações diretamente para os clientes a partir da base de dados do ERP, sem depender de regras automáticas.
  1. Selecione as guias, honorários ou acordos — por empresa ou individualmente.
  2. Escolha o canal: E-mail, WhatsApp ou ambos simultaneamente.
  3. Gere os textos: o sistema monta uma mensagem por empresa com todos os itens selecionados.
  4. Preencha o valor em cada campo editável inline (valores podem precisar de correção pela SELIC).
  5. Edite livremente o texto se necessário antes de copiar ou enviar.
  6. Copie e envie pelo seu cliente de e-mail, ou clique em "Enviar WhatsApp" para abrir já com a mensagem preenchida.
  7. Marque como enviado — só então o flag de notificação é registrado na sessão.
